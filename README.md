# 日本列島大地主ゲーム

日本の47都道府県を舞台に、土地の取得・通行料・建物投資で資産を競うローカル対戦型のブラウザゲームです。既存作品の名称や固有デザインを用いない、オリジナルの資産すごろくゲームとして実装しています。

## 遊び方

`index.html` をモダンブラウザで開くとプレイできます。GitHub Pages版は [こちら](https://tailofyukki-cell.github.io/nihon-daichi-game/) です。2〜4人が1台の端末を順番に操作して対戦します。

| 項目 | ルール |
| :--- | :--- |
| サイコロ | 1ターンにつき2個を振り、合計マスだけ進みます。 |
| スタート通過 | スタートを通過または到達すると2,000万円を受け取ります。 |
| 土地取得 | 未所有の都道府県に止まると、土地を購入できます。 |
| 通行料 | 他プレイヤーの土地に止まると、土地や建物に応じた通行料を支払います。 |
| 建設 | 同一地域グループを独占すると、家4棟からホテル1棟まで建設できます。 |
| 旅カード | 移動・収入・支出・休み・修繕費などのイベントが発生します。 |
| 勝利 | 他プレイヤーが全員破産した時点で、最後に残ったプレイヤーが勝者です。 |

## 土地競売

未所有の土地の購入を見送ると、土地はただちに競売へ移ります。破産していないプレイヤーが順番に入札でき、最高入札者以外が全員パスすると落札となります。

| 項目 | 仕様 |
| :--- | :--- |
| 最低入札額 | 土地の通常価格の25%を100万円単位に切り上げた額 |
| 入札単位 | 100万円 |
| 入札条件 | 現在の最高額より100万円以上高く、所持金以下であること |
| 入札なし | 全員が最初からパスした場合、土地は未所有のまま残ります。 |

## 資産整理：土地売却・抵当

ターン終了前には、所有地があるプレイヤーは **資産整理** を開けます。また、通行料・税金・カード支払いなどで所持金がマイナスになった場合、即時破産ではなく資産整理画面が自動表示されます。所持金を0万円以上に戻せば、そのままゲームを継続できます。

| 操作 | 仕様 |
| :--- | :--- |
| 建物売却 | 家またはホテルを1つずつ、建設費の50%で売却できます。 |
| 土地売却 | 土地を銀行へ売却します。未抵当の土地は購入価格の50%、建物は建設費の50%を返金します。 |
| 抵当 | 建物がない通常土地を購入価格の50%で抵当に入れられます。抵当中の土地は通行料が発生せず、地域独占による建設条件にも含まれません。 |
| 抵当解除 | 抵当額の110%を支払うと、土地を通常状態へ戻せます。 |
| 破産 | 資産整理しても支払えない、または整理を諦める場合は「破産する」を選択できます。土地と建物は銀行へ返却されます。 |
