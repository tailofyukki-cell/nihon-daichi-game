# 日本列島大地主ゲーム

日本の47都道府県を舞台に、土地の取得・通行料・建物投資で資産を競うローカル対戦型のブラウザゲームです。既存作品の名称や固有デザインを用いない、オリジナルの資産すごろくゲームとして実装しています。

## 遊び方

`index.html` をモダンブラウザで開くとプレイできます。GitHub Pages版は [こちら](https://tailofyukki-cell.github.io/nihon-daichi-game/) です。2〜4人が1台の端末を順番に操作して対戦します。

| 項目 | ルール |
| :--- | :--- |
| サイコロ | 1ターンにつき2個を振り、合計マスだけ進みます。 |
| スタート通過 | スタートを通過または到達すると3,000万円を受け取ります。 |
| 土地取得 | 未所有の都道府県に止まると、土地を購入できます。 |
| 給料日マス | 地域振興給料日（800万円）、観光収益給料日（1,000万円）、ふるさと給料日（800万円）に止まると収入を得ます。 |
| 通行料 | 他プレイヤーの土地に止まると、土地や建物に応じた通行料を支払います。 |
| 建設 | 同一地域グループを独占すると、家4棟からホテル1棟まで建設できます。 |
| 旅カード | 収入・支出・移動・選択肢・地域効果・通行料効果などのイベントが発生します。 |
| 勝利 | 50または80ターンなら総資産評価、無制限なら最後まで残ったプレイヤーで勝者を決めます。 |

## 多様な旅カード

旅カードは全37枚です。従来の移動・収入・支出・休み・修繕に加え、プレイヤーが効果を選べるカードと、所有地・地域・建物の状況に応じて価値が変わるカードを追加しました。支出カードで所持金がマイナスになった場合は、資産整理画面へ移行します。

| 分類 | 代表的な効果 |
| :--- | :--- |
| 選択肢カード | 「ご当地グルメフェス」では、400万円の収入または4マス前進を選べます。旅程変更では東京駅・博多駅のいずれかを選んで移動できます。 |
| 所有地・地域効果 | 所有地数、九州・沖縄・中部・関東の所有地数に応じて収入が増えます。 |
| 建物効果 | 家・ホテルの件数に応じた宿泊施設補助金を得ます。 |
| 通行料効果 | 次に自分の土地へ止まった相手から受け取る通行料を2倍にします。旅人パスポートは最大2回分の通行料を免除します。 |
| 戦略移動 | 所有する通常土地のうち、最も高額な土地へ移動できます。 |

## CPU（AI）対戦

ゲーム開始画面で各プレイヤーを **人間** または **CPU** に設定できます。CPUはローカル対戦に参加し、サイコロ、土地購入、競売、選択肢カード、建設、資産整理を自動で判断します。CPUは一定の資金を残しながら、購入可能な土地・独占に近い地域・建設可能な土地を優先します。

| CPUの判断 | 基本方針 |
| :--- | :--- |
| 土地購入 | 購入後も資金余力が残る場合、または地域独占に近づく場合に購入します。 |
| 競売 | 土地価格と手元資金に応じた上限額まで、100万円単位で入札します。 |
| 選択肢カード | 収入と移動効果を比べ、状況に応じて有利な選択肢を選びます。 |
| 建設 | 十分な資金余力がある場合、独占地域に家・ホテルを建設します。 |
| 資産整理 | 支払い不能時には建物売却、抵当、土地売却の順で資金化を試みます。 |

## ローカル戦績・ランキング

タイトル画面の **「戦績・ランキング」** から、対戦結果を確認できます。戦績はブラウザのローカルストレージに保存されるため、サーバー送信やアカウント登録は不要です。同じブラウザ・端末内でのみ保持され、画面からいつでもリセットできます。

| 集計項目 | 内容 |
| :--- | :--- |
| 対戦記録 | 直近20件の対戦を保存します。 |
| 総合ランキング | 勝数、平均総資産、対戦数の順で並べます。 |
| 人間／CPU区別 | 人間プレイヤーとCPUは別々に集計されます。 |
| 最近の対戦 | 日付、勝利条件、勝者、参加人数を表示します。 |

## ターン制限と総資産評価

ゲーム開始時に **50ターン・80ターン・無制限** から勝利条件を選択できます。ターン制限モードでは、全プレイヤーが指定ラウンドを終えた時点でゲームが終了し、総資産によって順位を決定します。無制限モードでは従来どおり、他プレイヤーがすべて破産した時点で最後の1人が勝者です。

| 評価要素 | 計算方法 |
| :--- | :--- |
| 所持金 | 現在の所持金をそのまま加算します。 |
| 土地評価額 | 所有地の購入価格を加算します。 |
| 建物評価額 | 家・ホテルの建設費を加算します。 |
| 抵当額 | 抵当に入れた土地の抵当額を控除します。 |
| 同額時の順位 | 総資産、所持金、所有地数の順で比較します。 |

> 総資産 = 所持金 + 土地評価額 + 建物評価額 − 抵当額

結果画面では、各プレイヤーについて現金・土地・建物・抵当額の内訳も確認できます。

## 収入バランスと現在位置表示

ゲームの資金循環を改善するため、スタート通過報酬を **3,000万円** に増額し、盤面上に3つの給料日マスを配置しています。給料日マスは停止時に確定収入を得られるため、土地購入や建設に向けた資金を作りやすくなります。

| マス | 収入 | 位置 |
| :--- | ---: | :--- |
| 地域振興給料日 | 800万円 | 四国エリア（マス14） |
| 観光収益給料日 | 1,000万円 | 近畿エリア（マス31） |
| ふるさと給料日 | 800万円 | 北関東エリア（マス51） |

現在手番のプレイヤーは、盤面上で**大型コマ・金色の発光枠・「現在地」ラベル**によって強調表示されます。他プレイヤーのコマも従来より大きく表示されます。

## 土地の競売

未所有の土地の購入を見送ると、土地はただちに競売へ移ります。破産していないプレイヤーが順番に入札でき、最高入札者以外が全員パスすると落札となります。

| 項目 | 仕様 |
| :--- | :--- |
| 最低入札額 | 土地の通常価格の25%を100万円単位に切り上げた額 |
| 入札単位 | 100万円 |
| 入札条件 | 現在の最高額より100万円以上高く、所持金以下であること |
| 入札なし | 全員が最初からパスした場合、土地は未所有のまま残ります。 |

## 資産整理：土地売却・抵当

ターン終了前には、所有地があるプレイヤーは **資産整理** を開けます。また、通行料・税金・カード支払いなどで所持金がマイナスになった場合、即時破産ではなく資産整理画面が自動表示されます。所持金を0万円以上に戻せば、そのままゲームを継続できます。

| 操作 | 仕様 |
| :--- | :--- |
| 建物売却 | 家またはホテルを1つずつ、建設費の50%で売却できます。 |
| 土地売却 | 土地を銀行へ売却します。未抵当の土地は購入価格の50%、建物は建設費の50%を返金します。 |
| 抵当 | 建物がない通常土地を購入価格の50%で抵当に入れられます。抵当中の土地は通行料が発生せず、地域独占による建設条件にも含まれません。 |
| 抵当解除 | 抵当額の110%を支払うと、土地を通常状態へ戻せます。 |
| 破産 | 資産整理しても支払えない、または整理を諦める場合は「破産する」を選択できます。土地と建物は銀行へ返却されます。 |

## サウンド・BGM

ゲーム開始時のユーザー操作をきっかけに、ブラウザ標準の **Web Audio API** でBGMと効果音を再生します。音声ファイルのダウンロードや外部サービスへの接続は不要です。

| 項目 | 内容 |
| :--- | :--- |
| BGM | 108 BPM・4小節の、明るく軽快なボードゲーム向けループBGMです。長時間のプレイを妨げない控えめな音量で再生します。 |
| 効果音 | ゲーム開始、サイコロ、土地購入、建設、通行料、給料日、税金、旅カード、スタート通過、破産、勝利で異なる音を再生します。 |
| 音量 | 画面右上の音量スライダーで0〜100%に調整できます。設定はこのブラウザに保存されます。 |
| ミュート | `音あり / ミュート中` ボタンでBGMと効果音をまとめて停止・再開できます。 |
| BGM切替 | `BGM: ON / OFF` ボタンでBGMだけを即時に切り替えられます。効果音は継続します。 |

> ブラウザの自動再生制限に対応するため、最初のゲーム開始またはサウンド操作を行った後に音声が有効になります。
